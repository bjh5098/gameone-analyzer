# gameone_analyzer

한양대학교 D-Dogs OB의 gameone.kr 박스스코어 데이터를 상황별(아웃카운트·주자상황 등)로
필터링해 타자/투수 스탯을 뽑아보기 위한 개인 분석 도구.

## 하고 싶은 것

"이런 상황에서 이 팀/선수 스탯이 어땠는지" 를 조건으로 조회하는 것.
엑셀의 필터 개념과 동일 — 조건을 정의하면 그 조건에 맞는 타석만 모아서 집계한다.

예: "2사 2·3루, 살곶이+배재고 구장 경기만" 조건으로 타율/안타 등을 뽑는 식.

## 페이지 구성 (feature 정의)

**타자 관점 페이지**와 **투수 관점 페이지** 2개로 구성된다. 둘은 별개 페이지이지만
아래 필터 조건은 완전히 동일한 구조를 공유한다 — 차이는 집계되는 스탯 종류뿐
(타자: 타율/안타/타점 등, 투수: 피안타율/자책점 등).

### 필터 조건 (타자·투수 페이지 공통, 확정)

1. **아웃카운트**: 무사(0사) / 1사 / 2사
2. **주자상황** (8가지):
   - 주자없음
   - 1루
   - 2루
   - 3루
   - 1·2루
   - 1·3루
   - 2·3루
   - 1·2·3루(만루)
   - 이 중 **득점권**은 2루 또는 3루에 주자가 있는 경우(2루, 3루, 1·2루, 1·3루, 2·3루, 만루) — 클러치 상황과 동일하게 취급
3. **구장 그룹핑**: 개별 구장 단독 조회(예: 살곶이만) 뿐 아니라 여러 구장을 하나로 묶어 합산 조회(예: 살곶이+배재고) 가능해야 함
4. **연도**: 시즌 단위(2024/2025/2026) 단독 조회 및 여러 시즌 합산 조회
5. **리그**: 리그명(예: 일요 싱글, 일요메이져, 일요리그(C조), 수요 야간 등) 단독 조회 및 여러 리그 합산 조회
   - 구장 그룹핑(3번)과 별개 축 — 같은 리그라도 구장이 다를 수 있고, 같은 구장에서 다른 리그 경기가 열릴 수 있음

### 확장 조건 (가능하면 추가)

6. **점수차**: 1점차 / 2점차 / 3점차 / 4점차 이상
   - 타석 시점 기준 점수차인지, 동점 상황을 별도 항목으로 둘지는 미확정 → [확인 필요]

## 데이터 소스

- 대상 URL 목록: [`games.md`](./games.md) — club_idx=31993 (한양대 D-Dogs OB) 2024~2026시즌 박스스코어
- 경기별 메타데이터(연도/날짜/리그/구장/상대팀/스코어): [`games_meta.csv`](./games_meta.csv)
- 각 URL은 서버사이드 렌더링 HTML이며, 이닝별 타석 이벤트 코드(안타/볼넷/삼진/병살 등)를 파싱해
  아웃카운트·주자상황을 순서대로 시뮬레이션해 재구성함 (사이트가 득점권 여부를 직접 제공하지 않음)

## 진행 상태

아직 수집/파싱 파이프라인 코드는 작성 전. `games.md`의 URL 목록과 `games_meta.csv`의
리그/구장 정보를 기반으로 경기별 파싱 → 타석 단위 상황 태깅 → 조건별 집계 순서로 구현할 예정.
상세 진행 계획과 파싱 로직(의사코드), 이벤트 코드 사전은 [`CLAUDE.md`](./CLAUDE.md) 참고.
